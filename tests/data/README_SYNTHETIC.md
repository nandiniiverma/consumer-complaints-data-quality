# SYNTHETIC test data - not real CFPB data

The two CSV files in this folder are **artificial**. They exist only to test the
validation logic and are generated by `tests/synthetic_data.py`.

| File | Rows | Purpose |
|---|---|---|
| `SYNTHETIC_test_data.csv` | 203 | 200 base rows with deliberately injected defects, plus 3 duplicate-ID rows |
| `SYNTHETIC_clean_data.csv` | 200 | The same base rows with no defects (every rule must pass) |

* Company names are invented ("Synthetic Bank A"...), complaint IDs start at 9,000,001.
* The exact number of defects injected for each rule is listed in `EXPECTED`
  inside `tests/synthetic_data.py`; `tests/test_validation.py` asserts that the SQL rules
  find exactly those numbers.
* The tests build their own temporary databases. They never touch `database/complaints.db`.
* If you run the pipeline on these files, use `--label "SYNTHETIC TEST DATA"` so every
  report and the dashboard carry a warning banner. Never report these numbers as CFPB results.
